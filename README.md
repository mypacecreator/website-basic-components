# ウェブサイト ワイヤーフレーム コンポーネントテンプレート

デザイン発注時にデザイナーへ渡すワイヤーフレームの元データ。このREADMEは自分用の管理メモ。

---

## ファイル構成

```
index.html   ← コンポーネント一覧ページ（ブラウザで直接開く）
style.css    ← ワイヤーフレーム用スタイル（CSS変数あり）
PLAN.md      ← 初期実装時の設計メモ（Claude が生成）
```

---

## 作成意図・設計方針

- **ワイヤーフレームとして**: レイアウト・構造・コンテンツ配置のみを示す。色・フォント・装飾はデザイナーが決める
- **WordPress コアブロック準拠**: 案件で使うブロックエディタのコンポーネントと対応させている
- **CSS変数（★マーク）**: `--color-primary` などデザイン確定後に更新が必要な箇所を ★ で明示
- フォーム系はブラウザデフォルト想定のため除外
- ヘッダーナビ・フッターはテーマ側で対応するため除外

### デザイナーへの渡し方

`index.html` をブラウザで開いて確認してもらう。デザイナーはコードを編集しない。Figma・XD 等のデザインカンプに各コンポーネントを作成していく。
